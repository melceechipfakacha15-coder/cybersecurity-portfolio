# Cybersecurity Portfolio

This repository documents my transition into IT and cybersecurity through practical labs, structured investigations, and clear technical writing.

My focus is defensive security: understanding how systems work, recognizing suspicious activity, investigating evidence, and communicating findings in a professional way.

## Current focus

- CompTIA A+ and IT support fundamentals
- Windows and Linux administration
- Networking concepts from the Network+ curriculum
- PowerShell and Bash fundamentals
- Security+ preparation
- Windows Event Logs, Wireshark, Splunk, Microsoft Sentinel, Active Directory, and Microsoft Entra ID

## Documentation standard

Every completed investigation will include:

1. Scenario and objective
2. Lab environment
3. Tools used
4. Evidence reviewed
5. Investigation process
6. Findings and indicators
7. Severity and business impact
8. Response and escalation
9. Recommendations
10. Lessons learned

## Career roadmap

1. Build IT support fundamentals and a Windows/Linux home lab.
2. Learn networking and begin applying for entry-level IT roles.
3. Prepare for Security+ and expand into security-focused labs.
4. Build SOC, SIEM, packet-analysis, and incident-response skills.
5. Learn Microsoft identity and security concepts and prepare for SC-900.
6. Pursue IT support, NOC, SOC, IAM, and junior security opportunities.

## Safety and ethics

All work in this repository uses authorized lab environments, simulated data, or sanitized evidence. Real credentials, private information, authentication tokens, employer data, and harmful payloads must never be committed.

See [SECURITY.md](SECURITY.md) before adding evidence or scripts.
