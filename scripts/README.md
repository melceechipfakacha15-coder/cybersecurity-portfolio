# Scripts

This directory will contain small, clearly documented automation examples developed during the roadmap.

Possible examples include:

- PowerShell system-information collection
- Windows event-log filtering
- Safe user and group inventory
- Basic network-diagnostic commands
- Log parsing in Python
- Reusable Splunk or Microsoft Sentinel queries

Each script should include:

1. Purpose
2. Supported environment
3. Safe-use notes
4. Inputs and outputs
5. Example command
6. Expected result
7. Limitations

Do not add offensive tooling, credential collection, destructive commands, secrets, or scripts intended for unauthorized systems.
