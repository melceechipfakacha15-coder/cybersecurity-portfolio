# Active Directory and IAM Security Review

**Status:** Planned

## Objective

Build and review a small identity lab that demonstrates least privilege, role-based access, group management, and secure account lifecycle practices.

## Skills demonstrated

- Identity and access management fundamentals
- Active Directory or cloud identity administration
- Least-privilege and role-based access review
- Account lifecycle documentation
- Security recommendation writing

## Planned environment and tools

- Isolated Windows Server Active Directory lab or authorized cloud identity sandbox
- Test users, groups, and roles
- PowerShell or platform administration tools
- Access review worksheet

## Investigation plan

1. Define fictional departments and job roles.
2. Create test users, groups, and access assignments.
3. Map roles to the minimum permissions required.
4. Review privileged access, inactive accounts, and group nesting.
5. Test onboarding, role change, and offboarding scenarios.
6. Document risks and recommend stronger identity controls.

## Evidence to collect

- Sanitized directory structure screenshots
- Role-to-access matrix
- Commands or configuration steps
- Access review findings
- Risk prioritization
- Remediation recommendations

## Deliverables

- IAM security review
- Role and permission matrix
- Sanitized evidence images
- Administration command reference
- Lessons learned

## Completion checklist

- [ ] Fictional lab identities created
- [ ] Roles and permissions mapped
- [ ] Privileged access reviewed
- [ ] Lifecycle scenarios tested
- [ ] Evidence sanitized
- [ ] Report proofread and published

## Safety note

Use fictional identities and an isolated or explicitly authorized environment. Never publish production tenant IDs, employee details, group memberships, credentials, or recovery information.
